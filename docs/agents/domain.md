# Domain Docs

This repository uses the single-context layout.

## Before exploring

- Read the root `CONTEXT.md`, if it exists.
- Read relevant decisions under `docs/adr/`, if that directory exists.
- If either is absent, continue silently. Create them lazily only when a
  domain term or durable architectural decision actually needs to be recorded.

## Vocabulary and decisions

Use the glossary's vocabulary in issue titles, proposals, tests, and code
discussions. If a needed term is missing or ambiguous, resolve it before
introducing a synonym. If a proposal conflicts with an existing ADR, call out
the conflict explicitly instead of silently replacing the decision.
